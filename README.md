# KoTalk デモ（中級韓国語 発音練習ウェブアプリ）

日本人の中級韓国語学習者向けのスマートフォン用ウェブアプリのデモです。
ビルド不要の静的サイト（HTML / CSS / JavaScript のみ）なので、そのまま公開できます。

## 機能

| 画面 | 内容 |
|---|---|
| ホーム | 今日の練習時間と目標（初期値15分）、連続日数、直近7日の練習日数、4週間の目標。初級・中級のテーマ一覧と最近の練習 |
| 会話練習 | テーマごとの**決まったシナリオ**でパートナーと会話。相手のセリフは ElevenLabs 音声（自動読み上げ可）。返事は韓国語で入力、または 🎤 で録音して声で返事（録音は再生可能。対応端末では音声認識で文字起こしして判定、非対応端末では判定せず参考の答えを表示）。**AI判定（Claude）を設定していれば、返事が場面に合っているかを AI が判定し、日本語のアドバイス・直した文・別の言い方を表示**（用意した答えと違っても意味が通じれば「通じた」）。AI未設定・接続失敗のときは簡易判定：韓国語として自然に終わる返事（〜요・〜다 など）なら「通じた」とし、用意した言い方と違うときは「こんな言い方もできます」を表示。今日の例文を使ってほしい場面（`require`）だけはキーワードで判定。通じなければヒントと例文を表示（2回で先に進む）。「使える表現を見る」で表現と文法解説 |
| 会話のまとめ | 練習時間・やりとり数・通じた返事、自分の返事一覧。中級テーマは「今日の例文」「関連単語クイズ」へ |
| 復習 | 中級テーマ：単語カード（🔊・カタカナ・覚えた／まだ）、関連単語クイズ（正誤と解説）、今日の例文（お手本音声・発音のポイント・表現の解説）。初級テーマ：使える表現 |
| 記録 | 練習時間（今日・7日・4週間）、連続出席と休息券、ポイント、講師1:1フィードバック交換 |
| 学習記録 | （`apiBase` 設定時）最初の会話の前に登録画面。東北大学の学生（クラスコード＋学籍番号）と TOFA の一般受講生（クラスコード＋ニックネーム＋性別・年代・学習歴・地域）で項目と同意文を分ける。保存への同意（必須）と研究利用への同意（任意）は別。登録しなくても使える。設定からいつでも変更・解除（記録の削除）ができる |
| 設定（右上の⚙️） | 1日の目標、学習記録の登録・変更、フィードバックの言語バランス、AI判定のオン・オフと接続確認、効果音、端末の対応状況 |

**ポイント:** 会話を最後まで終えると出席 +10pt（1日1回）、7日連続ごとに +30pt、クイズ正解1問 +2pt（1日1回）。300pt で講師1:1フィードバックと交換。

**テーマ:** 初級3（自己紹介・カフェで注文・道を聞く）、中級5（週末の約束・昨日のこと・好きな韓国料理・仕事の連絡・近くのお店を探す）。中級は `data.js` の例文・単語と連動。

## 仮実装（本番前に差し替える箇所）

コード内の `TODO(API)` で検索してください。

| 場所 | 現在 | 本番で接続するもの |
|---|---|---|
| `app.js` お手本ボタン | `audio/` の mp3（ElevenLabs で生成）を再生。`audio` 未指定の例文はブラウザ内蔵の音声合成 | 例文を追加したら同様に音声ファイルを追加 |
| `app.js` 講師フィードバック交換 | 端末内でポイントを減らすだけ | 申請・予約API（ポイント減算はサーバー側で確定） |
| `app.js` 会話の録音返事（`stopTalkRec`） | ブラウザの音声認識で文字起こし（端末により不可） | 音声認識APIをサーバー経由で呼び、どの端末でも判定 |
| `config.js` `apiBase` | 空（AI判定・学習記録なし） | `worker/` の Cloudflare Worker の URL。AI判定と学習記録（D1）に使う。手順は `worker/README.md` |
| `app.js` 会話（`startTalk` 付近） | 決まったシナリオ（`themes.js`）。返事の判定は AI（設定時）または簡易判定 | 自由な会話にする場合は、同じ Worker 経由で LLM に相手のセリフも作らせる |
| `app.js` 状態保存 | `localStorage`（端末内のみ） | ユーザー認証とサーバー側データベース |

> APIキーをフロントエンドに直接書かないでください。サーバーまたはサーバーレス関数を経由して呼び出してください。

## 端末の対応

- アプリ内ブラウザ（LINE・Instagram・Threads など）で開いた場合は、Safari / Chrome で開くよう案内を表示します
- MediaRecorder がない端末（古い iOS など）では、Web Audio を使った WAV 録音に自動で切り替えます
- お手本音声が鳴らないときは、原因の候補（マナーモード、韓国語音声が未インストールなど）を表示します
- iPhone でマイクの機能自体が無い場合（https なのに `getUserMedia` が無い）は「ロックダウンモード」が原因と見て、一時的にオフにする方法と、パソコンで開く方法を日本語で案内します。会話では、キーボードの音声入力で文字の返事ができることも表示します
- 設定タブの「この端末の対応状況」に、録音や読み上げに対応しているかを表示します

## デモ用操作

「出席」タブの下にあるボタンで動作を確認できます。

- **日付を1日進める:** 連続出席と休息券の動きを確認できます
- **+100pt:** 講師交換ボタンの有効化を確認できます
- **リセット:** すべてのデータを初期化します

## ローカルで確認

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。
録音には HTTPS 接続か localhost が必要です。

## 公開（GitHub Pages）

`.github/workflows/pages.yml` を同梱しています。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` ブランチに push すると自動で公開される

> 非公開（Private）リポジトリで GitHub Pages を使うには、GitHub の有料プラン（Pro など）が必要です。
> 無料プランの場合は、リポジトリを公開にするか、Netlify や Cloudflare Pages にフォルダごとアップロードしてください。

## ファイル構成

```
index.html   画面（練習 / 出席 / 設定 の3タブ）
style.css    スマホ向けスタイル（ダークモード対応）
themes.js    会話テーマのシナリオ（相手のセリフ・判定キーワード・ヒント・使える表現）
data.js      例文データ（5文、単語10語〔例文4＋関連6〕・発音ポイント・音声ファイル付き）
audio/       お手本音声 mp3（ElevenLabs 生成、1.mp3〜5.mp3）
audio/words/ 単語音声 mp3（ElevenLabs 生成、{レッスン}-{番号}.mp3）
audio/talk/  会話パートナーの音声 mp3（ElevenLabs 生成、{テーマ}-{番号}.mp3）
audio/sfx/   効果音 mp3（ElevenLabs 生成：correct＝正解、wrong＝不正解）
app.js       ロジック（会話・AI判定の呼び出し・録音返事・単語カード・クイズ・出席・ポイント）
config.js    公開してよい設定（サーバーの URL、同意文に入れる管理者・保存期間など）。APIキー・合言葉は書かない
docs/data-management-ja.md  学習記録の収集・管理方法（倫理審査用の下書き）
worker/      AI判定・学習記録のサーバー（Cloudflare Worker + D1。Claude API キーはここの secret にだけ置く）
```
