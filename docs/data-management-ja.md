# KoTalk 学習記録の収集・管理方法（案）

> 倫理審査・個人情報の取り扱い確認のための下書きです。【】の部分と「要確認」の項目は、所属機関の規程・審査委員会の様式に合わせて必ず書き換えてください。
> アプリ内の同意文は `config.js` の `consent` で同じ内容（管理者・保存期間・研究テーマなど）を設定します。両者が食い違わないようにしてください。

## 1. 概要

| 項目 | 内容 |
|---|---|
| システム名 | KoTalk（韓国語会話練習ウェブアプリ） |
| 研究課題名 | 【研究テーマ】 |
| 研究責任者 | 東北大学【部局・職名・氏名】 |
| 対象者 | (A) 東北大学の学生（【授業名】の履修者） / (B) TOFA【講座名】の一般受講生 |
| 収集期間 | 【開始日】〜【終了日】 |

対象者 A と B は、記録の管理者・利用目的・同意文を分けて扱う。アプリでは最初に区分を選び、区分ごとの同意文を表示する。クラスコードごとに区分をサーバー側で固定しており、区分を偽って登録することはできない。

## 2. 収集する情報

登録し、同意した人の分だけを保存する。登録しなくてもアプリのすべての機能を使える。

| 情報 | A 学生 | B 一般 | 備考 |
|---|---|---|---|
| クラスコード | ○ | ○ | 授業・講座の識別 |
| 学籍番号 | ○ | − | 授業での指導に使用 |
| ニックネーム | − | ○ | 本名でなくてよいと明示 |
| 性別 | − | ○ | 女性／男性／その他／回答しない |
| 年代 | − | ○ | 10代〜70代以上／回答しない（生年月日・年齢は取得しない） |
| 韓国語の学習歴 | − | ○ | 半年未満〜5年以上／回答しない |
| 居住地域 | − | ○ | 都道府県・海外／回答しない（市区町村以下は取得しない） |
| 会話練習の返事 | ○ | ○ | 入力した文字、または端末の音声認識で文字にしたもの。**録音の音声は保存しない** |
| 判定結果・AIのアドバイス・直した文 | ○ | ○ | |
| 練習日時・練習時間・やりとり数 | ○ | ○ | |
| 研究利用への同意の有無 | ○ | ○ | |

取得しないもの：氏名（学生の氏名は学籍番号と授業名簿で教員のみが照合可能）、メールアドレス、位置情報、録音音声、端末の識別子（広告ID等）。
端末ごとの乱数（device_token）を保存するが、これは本人が自分の記録を削除・同意変更するための照合用であり、書き出しには含めない。

## 3. 利用目的

| 区分 | 利用目的 | 同意 |
|---|---|---|
| A 学生 | 授業での学習状況の確認、指導・フィードバック。成績との関係：【例：練習量を平常点の参考にする／成績評価には使わない】 | 登録時に必須 |
| B 一般 | 受講生の学習状況の把握と指導、講座の改善 | 登録時に必須 |
| A・B 共通 | 研究「【研究テーマ】」での分析・発表 | **任意**（別のチェック欄） |

- 研究利用への同意は、記録の保存への同意とは別に、任意で取得する。
- 同意文に「同意しなくても授業・成績（A）、受講（B）には一切影響しない」と明記する。
- 要確認：A では成績評価者である教員が同意を求めるため、断りにくさ（強制性）への配慮が必要。例：研究同意の有無を授業担当者が成績確定まで見ない運用にする、同意の取得・管理を授業担当者以外が行う、など。
- 要確認：B の記録を東北大学の研究者が研究に利用する場合、TOFA から研究者への提供（第三者提供）に当たる。同意文で研究者と利用目的を明示しているが、TOFA 側のプライバシーポリシー・契約との整合を確認する。
- 要確認：B に18歳未満が含まれる可能性がある。同意文で保護者の同意を求めているが、確認方法（年代「10代」の扱いなど）を決める。

## 4. 研究で使うデータの加工

- 教員用の書き出し（CSV）には、通常用と研究用がある。
- 研究用の書き出しは、研究利用に同意した人だけを含め、学籍番号・ニックネームを仮ID（「P-」＋10桁の英数字）に置き換える。仮IDは書き出し用の合言葉を混ぜたハッシュで作るため、合言葉を知らない人は元の番号に戻せない。
- 研究用データには学籍番号・ニックネームを含めない。属性（B の性別・年代・学習歴・地域）は区分ごとの集計に使い、少人数で個人が特定されるおそれがある集計結果は公表しない。【例：5人未満のセルは公表しない】
- 返事の文に、学習者が自分の個人情報（名前・勤務先など）を書く可能性がある。公表時には該当箇所を伏せる。

## 5. 保存場所と安全管理

| 項目 | 内容 |
|---|---|
| 保存先 | Cloudflare D1（Cloudflare, Inc.、米国）。データの保存場所は国外を含む可能性がある。要確認：外国にある第三者への提供・委託としての扱いと、同意文での説明の十分さ |
| AI判定 | AI判定がオンのとき、返事の文と会話の場面情報が Anthropic, PBC（米国）の Claude API に送信される。学籍番号・ニックネーム・属性は送信しない。要確認：Anthropic の API 利用規約上のデータ保持期間・学習への利用の有無（Console の設定・最新の規約で確認） |
| 通信 | HTTPS で暗号化 |
| 受け付ける相手 | 許可したウェブサイトからの要求のみ受け付ける。記録は登録済みの端末からのみ受け付ける |
| 書き出し | 合言葉（EXPORT_KEY）を知っている教員のみ。合言葉は Cloudflare の秘密情報として保存し、公開ファイルには書かない |
| 端末側 | 学習者の端末のブラウザにも練習時間などが保存される（本人のみが見られる） |

## 6. 保存期間と削除

- 保存期間：A【例：2027年3月31日まで】／B【例：講座終了後1年間】。期間終了後、管理者が該当クラスの記録を削除する。
- 研究用に書き出したデータ（仮ID化したもの）の保存期間：【例：研究終了後5年間。東北大学の規程に従う】
- 本人はいつでもアプリの「設定 → 学習記録」から登録を解除でき、そのとき本人の記録（登録情報・返事・練習記録）がサーバーからすべて削除される。
- 研究への同意を取り消した場合、それ以降の研究用の書き出しから本人の記録は除外される。要確認：取り消し前にすでに書き出し・分析したデータの扱い（例：論文公表後は削除できない旨を同意文に書くか）。
- 端末を変えた・ブラウザのデータを消したなど、本人がアプリから削除できなくなった場合は、問い合わせ先に連絡してもらい、管理者が削除する。

## 7. 問い合わせ先

- A：【担当教員名・メールアドレス】
- B：【TOFA 担当者名・メールアドレス】
- 研究について：【研究責任者名・メールアドレス】

## 8. アプリ内で表示する同意文

アプリでは区分ごとに次の内容を表示する（`app.js` の `consentHtml`。管理者名・保存期間などは `config.js` から差し込む）。

- 保存する情報（上の表と同じ範囲）
- 利用目的（A は成績との関係を含む）
- 保存先（Cloudflare、国外の可能性）、AI判定時の送信先（Anthropic、米国）
- 保存期間、管理者・問い合わせ先
- 登録の解除と記録の削除の方法
- B のみ：18歳未満は保護者の同意が必要であること
- 研究での利用（任意）：研究者・研究テーマ・仮IDへの置き換え・同意しなくても不利益がないこと・取り消しの方法

同意は「学習記録の保存への同意（必須）」と「研究での利用への同意（任意）」の2つのチェック欄で取得する。
